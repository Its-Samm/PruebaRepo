# Samuel David Caicedo Rodriguez - Mi Curriculum

Hoja de vida (CV) wub personal desarrollada con **HTML5**, **CSS3** y **Picocss** como, entregra de la actividad programa el dia de hoy parcial 1 - Programacion ambiente web.

## Contenido

El sitio Presenta el perfil profecional de Samuel david caicedo Rodriguez, Estudiante de Ingenieria de sistemas.

Organizado en las secciones exigidadas por la guia de la actividad

- Informacion personal
- Perfil profecional (sobre mi)
- Formacion academica
- Experiencia Laboral
- Habilidades
- Contacto

## Tecnologias utilizadas

- **HTML5** con etiquetas semanticas ('heder', 'main, 'section', 'artiicle', 'address', 'footer')
- **CSS** propio ('styles.css') para la tipografia, layout y responsive
- **PicoCSS (htpps://picocss.com/)** como framework base, con via CND
- Tipografia **Fraunces** (titulos) e **IBM Plex Sans** (texto), via google fonts
